## Области опыта

**Финансовые системы.** Торговые и инвестиционные платформы, P2P-платежи, криптопроцессинг и Web3-проекты. Приём платежей, выплаты, распределение заявок, балансы, комиссии, споры и отчётность.

**Сервисы для бизнеса.** Личные кабинеты и административные системы, роли доступа, аналитика, API и автоматизация процессов.

**Приложения и ИИ.** Приложения для macOS и Android, Telegram-боты и браузерные расширения. Распознавание текста и речи, перевод, интеграции с ИИ-моделями.
